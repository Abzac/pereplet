# Проверка готовности Переплёта 0.1.0

Проверено локально 24 ноября 2026 года. Имя репозитория: pereplet.
Версия: 0.1.0, будущий тег: v0.1.0. Ничего не опубликовано.

## Завершённые проверки

- Версии frontend, Tauri и Cargo согласованы; проверка RELEASE_TAG=v0.1.0 проходит.
- README, реальные скриншоты, руководство FB2 и 12 классических книг подготовлены.
- PDF, CBZ и CBR проверены в браузере с настоящим локальным backend и отдельной тестовой базой: переход вперёд/назад, разворот, клавиатура, открытие и закрытие настроек, восстановление позиции после повторного открытия. Ошибок JavaScript нет. Ранее замеченный сбой CBZ не воспроизведён; исправление неизвестной причины не заявляется.
- Поиск Пратчетта на двух внешних OPDS-серверах возвращает авторов. Полные имена и порядок объединённой выдачи проверялись ранее; это не гарантия одинаковых возможностей любого внешнего OPDS-сервера.
- Gutenberg вернул 503; Lib.ru открывает корень, но поиск возвращает некорректный XML. Оба исключены из начального набора новых установок. Сохранённые каталоги существующих библиотек не изменяются.
- Проверены лицензии компонентов, дополнены уведомления и исходники MPL. Отдельный отчёт: LICENSE_AUDIT.md.
- Личный профиль, книги и настройки не используются для сборки. Локальный репозиторий подготовлен без remote.

## Что остаётся

- Разрешить открытые вопросы из LICENSE_AUDIT.md перед публичным распространением.
- Архивы и установщик подготовлены как локальные кандидаты с обновлённым комплектом лицензий. Наличие кандидата не снимает открытых вопросов перед публикацией.
- Создание GitHub-репозитория, push, запуск GitHub Actions и публикация релиза не выполняются без отдельного разрешения. Проверка Actions и чистой Windows по решению владельца отложена; локальные тесты её не заменяют.

Сертификат подписи Windows и автоматическое обновление не входят в этот выпуск.
